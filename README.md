# ⚡ Mysticbound - Card Game

A browser-based magic card game built with vanilla HTML, CSS, and JavaScript. Collect cards, build decks, level up, and battle enemies!

## ✨ Features

- **Turn-Based Battles** - Strategic card gameplay with mana system
- **Card Collection** - Collect 18+ unique cards with different rarities
- **Deck Building** - Customize your 30-card deck before battle
- **Leveling System** - Gain XP from victories and level up
- **Gold Rewards** - Earn gold from battles (currency for future features)
- **Persistent Saves** - Your collection and progress are saved locally
- **Filter System** - Filter cards by Attack, Heal, or Defend type
- **Rarity Badges** - Common, Rare, Epic, and Legendary cards
